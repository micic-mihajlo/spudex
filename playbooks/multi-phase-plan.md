### Multi-phase or multi-PR plan

1. State the target end state.
2. Split phases by independently verifiable outcomes.
3. Identify shared state, ordering constraints, and rollback points.
4. Keep each phase landable.
5. Use `show-me-your-work` when the trail matters.
6. Run **Opening a PR** for each phase only when publishing is part of the task.

Reply with phases, dependencies, verification per phase, and the first concrete action.
