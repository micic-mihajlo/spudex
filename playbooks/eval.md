### Eval

1. State the behavior being evaluated and the promotion bar.
2. Build candidates that differ in one meaningful variable.
3. Use realistic prompts or artifacts. Do not leak the intended answer into validation.
4. Run each candidate in a fresh context when possible.
5. Grade from artifacts. Prefer transcripts, diffs, command output, and produced files over self-report.
6. Promote only if the winning candidate clears the stated bar.

Reply with the candidates, the bar, the evidence, the winner, and the tradeoff.
